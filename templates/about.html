About the Project

The Blockchain Cyber Threat Intelligence Platform is a web application developed using Python and Flask. It enables organizations and security professionals to securely share cyber threat intelligence using a lightweight blockchain. Every submitted threat is stored in a blockchain block protected with SHA-256 hashing to ensure integrity and prevent unauthorized changes.

Project Objectives

Threat Detection

Detect malicious URLs, domains, IP addresses, email addresses and malware hashes.

Blockchain Security

Store cyber threat reports securely using an immutable blockchain ledger.

Threat Sharing

Share verified cyber threat intelligence among multiple users securely.

System Workflow

Step 1

User checks or submits a cyber threat.

Step 2

Threat data is validated by the application.

Step 3

Threat is stored in SQLite database.

Step 4

Blockchain generates a SHA-256 hash and creates a new block.

Step 5

Users can verify the blockchain ledger and browse reported threats.
